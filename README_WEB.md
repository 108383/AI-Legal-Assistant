# 智律 Web 使用指南

智律 Web 页面提供法律问题输入、资料检索回答与历史咨询管理。项目整体架构、技术实现和安装方式见 [项目介绍](README.md)。

## 咨询流程

1. 点击“新建咨询”，输入问题或选择快捷问题。
2. 描述事情发生的时间、地点、相关主体和关键事实，避免提供身份证号等不必要的敏感信息。
3. 查看生成的回答，并核验相关法规、引用和资料的适用性。
4. 继续提问补充事实，或在历史列表中切换已有咨询。

## 历史管理

首次提问后会自动创建会话，系统根据问题生成简短标题。历史记录保存在服务端，可以重新加载消息并继续咨询。

点击历史条目旁的删除按钮，确认后将永久删除该会话。其他会话不受影响。回答生成期间不允许删除，已删除记录无法恢复。

## 页面交互

- Enter 发送问题，Shift + Enter 换行。
- 回答以流式方式展示，支持 Markdown 列表与链接。
- 停止按钮中止浏览器读取，不保证立即取消后端模型调用。
- 移动端通过顶部菜单打开历史侧栏。

## 服务部署

单用户本地运行使用 `python web_app.py`。服务器运行可使用：

```bash
uvicorn web_app:app --host 0.0.0.0 --port 8000
```

反向代理需关闭 SSE 响应缓冲，并配置 HTTPS。历史目录与向量库目录需要持久化存储。对外开放前，应增加登录、会话访问权限和限流。

回答仅供法律信息参考，涉及重要权益时请咨询执业律师。
